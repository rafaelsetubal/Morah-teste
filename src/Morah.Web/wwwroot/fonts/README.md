# Fontes locais

Poppins principal, pesos 400/600/700. Roboto apoio, pesos 400/600/700. Material Symbols Rounded, peso 400, FILL 0, GRAD 0, opsz 24.

Arquivos obtidos dos endpoints oficiais Google Fonts e Google Fonts Static. Regras locais em ../css/fonts.css, sem CDN em execução. Carbona não é utilizada.

Os botões do Figma usam Inter; a substituição por Poppins foi autorizada pelo usuário, conservando tamanho, peso e altura de linha.
